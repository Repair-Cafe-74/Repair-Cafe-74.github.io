# Redirections vers le nouveau site

On trouve ici les fichiers qui permettent de gérer les redirections depuis l'ancien site Wordpress hébergé chez Free.

=> ancienne URL : http://repaircafe74.free.fr

Il faut garder cette config live chez Free car l'URL ci-dessus se trouve partout, y compris sur des cartes
d'invitations ou des flyers.

## Les fichiers

- ``ìndex.php`` est le fichier à la racine du compte Free : il gère les redirections de l'ancien site
- ``.htaccess`` est le fichier de redirection de la partie Admin de Wordpress de l'ancien site
    - il redirige vers la page d'admin de Decapcms du nouveau site
